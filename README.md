## What is CPU Temp Monitor?

CPU Temp Monitor is a lightweight temperature monitor for PC. It shows your CPU and GPU temperatures as live icons in the Windows system tray, so you can check CPU temp at a glance without opening heavy hardware monitoring software.

Use it to watch processor heat while gaming, track video card temperature under load, catch overheating early with alerts, and see min / max values over time.

## Features

- Real-time **CPU temperature** and **GPU temperature** in the system tray
- Separate or combined tray icons with temperature-based colors
- Current, minimum and maximum CPU / GPU temperatures
- Overheating alerts for CPU and GPU
- CPU and GPU load indicators
- RAM and VRAM usage
- On-screen display (OSD) with temps, load and FPS counter
- Detailed hardware info: CPU, GPU, RAM, motherboard, BIOS, storage
- SMART and drive health information (when supported)
- Light and dark themes, DPI-aware interface
- Start minimized to tray, optional Windows startup
- **Portable** — single EXE, no installation required
- Free and open source

## How to use

1. Download the latest release from SourceForge.
2. Run `CPU-Temp-Monitor.exe` — no installation needed.
3. CPU and GPU temperature icons appear in the system tray.
4. Open the main window to see detailed temps, load and hardware info.

## FAQ

**How do I check my CPU temperature on Windows 11?**
Run CPU Temp Monitor — the current CPU temperature appears in the system tray immediately.

**Can it monitor CPU and GPU temperature at the same time?**
Yes. CPU and GPU temps are shown side by side, as separate or combined tray icons.

**What is a normal CPU temperature?**
Typically 30–50 °C at idle and 60–85 °C under heavy load, depending on your processor and cooling.
